# Project Memory & Corrections Log (Moss & Daisy)

1. Stack (IT314 Rubric): ReactJS + Vite + TypeScript + React-Bootstrap + React Router + Motion + Zustand + Sass + Oxlint.
2. Theme: Carbon Black (#121412), Daisy White (#FBFAF5), Mossy Green (#4F6F37 light / #8FB36B dark).
3. Reference Designs:
   - INSTANT Photo Studio (thin moss hairlines around uppercase titles, 2x2 category tiles, underline contact form)
   - HARVEST Bakery (dark artisanal hero, Desktop + Mobile layouts, 3-icon feature card, circular quality badge, product grid)
   - GAZU & NORD (warm Daisy-White light editorial mode, oversized hero background wordmark, dark 3-column category strip, trust bar)
4. Live Ingredient Pricing & Live Plate/Box Display:
   - Every dish has a base prep price + per-ingredient PHP prices.
   - Editing ingredients updates the visual Plate/Bowl/Bento-Box and PHP price + calories live on screen.
5. Named Asset Folders:
   - 84 folders under public/images/ (5 containers, 18 foods, 61 ingredients) with temporary preview.svg graphics.
   - Drop any custom image into any folder and run .\sync-images.ps1 to replace its temporary graphic.
6. Delivery & Home Features:
   - Confirm delivery address before delivering.
   - Delivery History with order details and 1-tap Reorder.
   - Previously Ordered items shown on the Home page.
   - Healthy Food Recommendations & Smart Healthy Swaps.
7. Workflow: 6 Phases (Design -> Layout -> Functions -> Animations -> Testing -> Finalizing).
